# Company Filing Analyzer

An interactive and intelligent SEC / Company Filing Analysis web dashboard built with React, Vite, and Tailwind CSS.

## 🚀 Features

- **Interactive Filing Analysis**: Real-time insights and breakdowns into quarterly & annual reports (10-K, 10-Q, 8-K).
- **Financial Metrics & KPIs**: Instant visual indicators for revenue, operating margin, EPS, and debt-to-equity ratios.
- **Risk Assessment & Key Highlights**: Highlighted summary points and risk factors identified across disclosures.
- **Modern Responsive UI**: Clean glassmorphism styling, dark mode accents, and smooth transitions.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: [Vercel](https://vercel.com/)

## 💻 Local Development

Clone the repository and install dependencies:

```bash
git clone https://github.com/kishorels/company-filing-analyzer.git
cd company-filing-analyzer
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

## 🌐 Deploy to Vercel

1. Push this repository to GitHub.
2. Go to [Vercel](https://vercel.com/) and click **Add New Project**.
3. Import `company-filing-analyzer` from your GitHub account.
4. Framework Preset will be auto-detected as **Vite**.
5. Click **Deploy**!
